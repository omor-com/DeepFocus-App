# DeepFocus — Official Landing Website

Official static website for **DeepFocus**, an Android productivity and focus application developed by **Muhammed Omor**, serving users in Bangladesh with **Bangla (`বাংলা`) as the default language** and **English** as the secondary language.

- **Live Website:** https://deepfocus.asf.run/
- **Official Product Listing:** https://www.supportkori.com/muhammedomor/extras/deepfocus-app-ts3g
- **Developer:** Muhammed Omor
- **Technology Stack:** Pure HTML5, CSS3, and Vanilla JavaScript (zero runtime frameworks, zero external CSS/JS/font CDNs, zero backend)

## Project Files (Deployable from Root or `deepfocus-landing/`)

```text
.
├── .nojekyll           # Prevents GitHub Pages Jekyll from replacing assets/css/style.css
├── index.html          # Main landing page (Bangla default + EN toggle + Schema.org JSON-LD)
├── features.html       # Detailed feature breakdown & Android limitations
├── faq.html            # Full 12-question bilingual FAQ + FAQPage JSON-LD
├── privacy.html        # Final Privacy Policy (based on SupportKori & static site behavior)
├── terms.html          # Final Terms & Conditions
├── 404.html            # Custom bilingual 404 page
├── robots.txt          # Crawler rules (Googlebot, Bingbot, OAI-SearchBot)
├── sitemap.xml         # Live sitemap for https://deepfocus.asf.run/
└── assets/
    ├── css/
    │   └── style.css   # Mobile-first stylesheet with Bangla-ready system fonts
    └── js/
        └── main.js     # Bangla-default EN/বাংলা switcher, mobile menu, FAQ, lightbox
```
